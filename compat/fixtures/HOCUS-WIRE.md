# Hocuspocus wire golden fixtures

`hocus-wire.json` is generated by `compat/js/generate-wire-fixtures.mjs` using the
pinned `compat/js/package-lock.json` dependencies:

- `@hocuspocus/provider@4.6.0`
- `@hocuspocus/common@4.6.0`
- `yjs@13.6.32`, `y-protocols@1.0.7`, `lib0` (transitive)

Client goldens are captured from the installed provider outgoing constructors
(`AuthenticationMessage`, `SyncStepOneMessage`, `UpdateMessage`,
`AwarenessMessage`, `StatelessMessage`, `CloseMessage`) and `sendPong`.
`Y.Doc.clientID` is fixed at `12345`. Auth token is that awareness clientID
decimal, not a session JWT. Session multiplexing uses `makeRoutingKey`
(`documentName\\0sessionId`); room parse runs on the document-name half.

Provider `MessageType` has no opcode 4 (`SyncReply`) or 6 (`BroadcastStateless`).
`SyncStepTwoMessage` is still `MessageType.Sync` (0). Ping is the single byte
`09`; Pong is `writeVarUint(10)` with no routing key. Persist strings are
`persist:` / `persisted:` / `persist-failed:` plus a request UUID. Authenticated
scopes are `readonly` and `read-write`.

Regenerate after codec changes:

```bash
npm --prefix compat/js ci --ignore-scripts --no-audit --no-fund
node compat/js/generate-wire-fixtures.mjs
```

The generator destroys awareness and Y.Docs so Node exits. The Rust
`collab_wire` integration test decodes each golden `hex` case and re-encodes to
identical bytes. Malformed rows document expected rejections only.
