# Web e2e harness: intent and differences

TypeScript under `scripts/web-e2e/`, run by Bun, replaces the Python and shell harness. Caller-visible flags, exit codes, stage lines, redaction, and files written stay. Line-by-line shell text does not.

| --------------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scripts/web-e2e-groups.py`                               | `scripts/web-e2e/groups.ts`                                         | `list-groups`, `shard-jsonl --index --shards`, `verify --shards`; JSON lines; exit 1 on fail-closed discovery                                             |
| `scripts/test_web_e2e_groups.py`                          | `scripts/web-e2e/groups.test.ts`                                    | Same discovery, sharding, and unsupported-path failures, with fixed expectations                                                                          |

## Differences

- `bash -n` syntax checks are gone with the shell files. Bun parses the TypeScript entrypoints when the tests import them.
- Argparse usage text is not copied. Callers that fail closed match the previous error substrings and exit codes.
- Tests that read `scripts/run-web-e2e.sh` as bash source (`scripts/fixtures/sqlite-ci/test-wiring.py` preflight copy, `scripts/selected-backend-ci/test_early_driver_failure.py`, `scripts/fixtures/web-e2e/test-build-handoff.py`, `tools/selected-backend-ci/runner.test.ts`) still name that path. This batch does not rewrite those owners. After the shell file is deleted, those readers fail until their owners move to `scripts/web-e2e/run.ts`.
- Selected-companion `sudo`/`setpriv`/`python3 scripts/run-selected-backend-e2e.py` argv stays. `--selected-footer` runs only that companion for a caller that previously sliced the shell.
- Network-settle and netlink markers use the same messages. Timestamps are UTC ISO-8601 with microseconds instead of bash `EPOCHREALTIME`.
- ZIP reading supports stored and deflate members. The summary text matches the previous columns and redaction rules.
