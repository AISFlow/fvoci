## Confirmed decisions and scoped technical recommendations

- Quick capture, task and note are input intentions. Classification is optional; reuse documents/tasks instead of requiring three independent stores. Never silently convert every note into a task.
- Personal content starts private. Reuse the existing **personal workspace** as the recommended default; team creation/invitation and personal→team move/share require explicit destination and disclosure confirmation. A link, lookup, Zotero group grant or lack of a public share token never widens original ACL. Existing team wiki ACL remains workspace-based.
- Rich, block, **EDITABLE Markdown**, and preview operate on one live CRDT document and docID. Markdown is a generated projection, not recovered original source. Preserve rich features, block/reference IDs and attachment relationships. Detect touched unrepresentable data, offer warning/Cancel, and reject stale Apply; no separate saved mode copies.
- One person has one running stopwatch by default, including across workspaces. Start/pause/resume/stop, correction, daily records and day/week totals use server time and durable intervals; ticker only displays. Pause is excluded, Stop does not complete a task. Existing per-workspace open time entry uniqueness is insufficient for this final guarantee.
- Study/research planning reuses projects/tasks/documents and small templates: goals, reading, resources, notes and estimated/actual time. No dedicated education engine; completion-based recurrence stays distinct from due-date recurrence.
- Zotero 0.5 reads bibliography and collections only, maps remote identity stably and links local documents/tasks back to the source. PDF/annotation collection, remote writes and two-way sync remain explicitly outside this confirmed iteration. User-authored local work survives remote deletion/revocation.
- Free trial SaaS and self-hosting both require tenant isolation, recovery, resource limits and data exit. No billing/seats/subscriptions. These requirements cannot be waived with a feature flag or a future label.

W2 should retain UUID as object identity and resolve current display routes after rename/move. Reuse creation provenance (`task_origins`) separately from body-derived backlinks. Source/target ACLs are independently evaluated, including attachment/search/snippet/count delivery. Personal quick tasks should be explicitly self-assigned for MyTasks; team task assignment remains an explicit choice. Source checkbox and task status are separate until an explicit synchronization operation is implemented; no hidden mirrored state.

Recommended date policy: date-only stays an ISO calendar date; an instant stays UTC; day/week allocation uses the account's IANA timezone (existing configured fallback when absent). Freeze the reporting timezone per query and show it; changes reallocate presentation without changing UTC intervals. W5 owns final interval/correction DTO policy and its review. Unfinished sessions remain running through browser close/logout, visibly recover after authorized reload, and never invent an end time. Offline start/stop requests are unconfirmed commands, not fabricated server-timed intervals. Native user restore targets a fresh authorized tenant with explicit ID mapping; overwriting existing data is not authorized.
