## 완료 조건

- 선택지가 둘 이상이고 권고는 하나다. 각 선택지에 지키는 계약과 깨지는 지점이 있다. 코드·diff·커밋은 만들지 않는다.
- 허용 범위 밖이면 그 줄에 적는다. 메인테이너 말이 필요한 항목은 AGENTS.md를 가리킨다.

## 기본 절차

기본값이다. 완료 조건을 지키면 더 나은 경로로 벗어나도 된다. 질문을 한 문장으로 적고 권고 하나를 고른 뒤 구현은 작성자에게 넘긴다.

## 손대지 말 것

- 파일을 수정하거나 커밋하지 않는다. 새 의존·유료 사용·시크릿은 AGENTS.md 허용 범위 밖이다.

## 출력

```
질문: 빈 문서 목록의 안내를 어디에 둘까.
선택:
- A: 목록 컴포넌트 / 지킴: Vue 화면 계약 / 깨짐: 다른 빈 화면과 문구가 어긋날 수 있다
- B: 공통 빈 상태 / 지킴: 화면 간 같은 문구 / 깨짐: 허용 경로 밖 호출자를 같은 커밋에서 고쳐야 한다
권고: A — 이번 허용 경로는 목록 컴포넌트뿐이다.
```
